# Balance Ball: Salone Edition — browser prototype v0.2

Open `index.html` in a browser, or upload it to any static hosting provider.

Controls: WASD / arrow keys or mobile virtual joystick. Space / DODGE triggers a short evasive dash.

Rules implemented: One ball, two opposing automated throwers, free movement in the middle, three players per team, next player enters when hit, next team enters when all three are out.

This is a lightweight 2D mechanics prototype, not yet the planned stylized 3D Godot game. No networking, accounts, leaderboard or multiplayer. Survival time is a provisional digital scoring mechanic, not a verified traditional rule.

For a public link: publish index.html using GitHub Pages, Netlify, or similar static hosting. Test mobile browser touch controls before sharing broadly.
